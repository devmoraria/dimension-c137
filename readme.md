# 🧪 Rick and Morty — Dimension C-137 Portal
An interactive, responsive web application inspired by the universe of the Rick and Morty series. The project simulates the interdimensional travel experience using the Portal Gun—generating classic quotes from the show—and integrates with the official API to explore characters from the multiverse.

Rick and Morty Preview

🚀 Features
🌀 Dimensional Effect (Portal Gun): Firing the portal gun triggers an animated giant vortex on the screen, simulating interdimensional travel and revealing classic, iconic character quotes.
✨ Animated Cosmic Background: Real-time canvas rendering of stars with continuous animation using vanilla JavaScript.
🛸 Character Explorer: Integrates with The Rick and Morty API, featuring name search and combined filters for Status (Alive, Dead, Unknown) and Gender.
📄 Dynamic Pagination ("Load More"): Supports page-based navigation to gradually load the 800+ characters registered in the database.
🔍 Details Modal: Click any character card to view detailed information such as species, origin, current location, and number of episode appearances.
❓ Interactive FAQ: Frequently Asked Questions section featuring a functional accordion.
📱 Fully Responsive: Fluid layout optimized for desktops, tablets, and mobile devices.
🛠️️ Technologies Used
HTML5: Semantic and accessible structure.
CSS3: Flexbox, CSS Grid, CSS variables, custom animations, and gradient/vortex effects. - JavaScript (ES6+): DOM manipulation, Canvas API, Fetch API (asynchronous), and events.
The Rick and Morty API: REST API for fetching data and images from the multiverse.
Google Fonts: Creepster (Rick & Morty theme) and Space Grotesk typefaces.

An interactive, responsive web application inspired by the universe of the **Rick and Morty** series. The project simulates the interdimensional travel experience using the *Portal Gun*—generating classic quotes from the show—and integrates with the official API to explore characters from the multiverse.

![Rick and Morty Preview](https://rickandmortyapi.com/api/character/avatar/1.jpeg)

---

## 🚀 Features

- **🌀 Dimensional Effect (Portal Gun):** Firing the portal gun triggers an animated giant vortex on the screen, simulating interdimensional travel and revealing classic, iconic character quotes.
- **✨ Animated Cosmic Background:** Real-time canvas rendering of stars with continuous animation using vanilla JavaScript.
- **🛸 Character Explorer:** Integrates with [The Rick and Morty API](https://rickandmortyapi.com/documentation), featuring name search and combined filters for **Status** (Alive, Dead, Unknown) and **Gender**.
- **📄 Dynamic Pagination ("Load More"):** Supports page-based navigation to gradually load the 800+ characters registered in the database.
- **🔍 Details Modal:** Click any character card to view detailed information such as species, origin, current location, and number of episode appearances.
- **❓ Interactive FAQ:** Frequently Asked Questions section featuring a functional accordion.
- **📱 Fully Responsive:** Fluid layout optimized for desktops, tablets, and mobile devices.

---

## 🛠️️ Technologies Used

- **HTML5:** Semantic and accessible structure.
- **CSS3:** Flexbox, CSS Grid, CSS variables, custom animations, and gradient/vortex effects. - **JavaScript (ES6+):** DOM manipulation, Canvas API, Fetch API (asynchronous), and events.
- **The Rick and Morty API:** REST API for fetching data and images from the multiverse.
- **Google Fonts:** *Creepster* (Rick & Morty theme) and *Space Grotesk* typefaces.
